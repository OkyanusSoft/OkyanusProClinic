# سجل النسخ الاحتياطي — دفعة 2026-08-29 04:00 (إصلاح رفض MySQL لتواريخ ISO)

## الخطأ المبلَّغ عنه
`Incorrect datetime value: '2026-08-29T01:10:19.651Z' for column sharafi_dental.supply_moves.date`

## السبب الجذري
أعمدة DATETIME في MySQL ترفض صيغة ISO 8601 ذات اللاحقة `Z` والمللي ثانية في الوضع الصارم.
الخادم كان يمرر `supply_moves.date` (وهو نص ISO من الواجهة) كما هو دون تحويل.

## التعديل — server/index.js
1. إضافة دالة `toMySqlDateTime(v)` — تحوّل أي قيمة (نص ISO أو Date) إلى `YYYY-MM-DD HH:MM:SS` الصالحة، أو null للقيم الفارغة/غير الصالحة.
2. استخدامها في ثلاث مواضع إدراج:
   - `supply_moves.date` (مصدر الخطأ)
   - `follow_ups.createdAt` (دفاعياً)
   - `users.lastLogin` (دفاعياً)

## التفعيل
إعادة تشغيل الخادم: `npm start` داخل مجلد server — ثم «مزامنة الآن» من الإعدادات.

## النسخة الكاملة السابقة للخادم
`_backups/` تحتوي نسخ الواجهة؛ الخادم أُعيدت كتابته بتاريخ 2026-02-19 (إنشاء الجداول الذاتي) وهذا التعديل طفيف وموثق أعلاه وقابل للعكس بحذف الدالة واستعادة `?? null`.

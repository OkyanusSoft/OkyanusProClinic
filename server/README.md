# خادم قاعدة البيانات المركزية — MySQL

يحوّل هذا الخادم نظام العيادة من التخزين المحلي إلى **قاعدة بيانات MySQL مركزية** مشتركة بين كل الأجهزة.

## 1) تجهيز MySQL
```bash
mysql -u root -p < schema.sql
```
ينشئ قاعدة `sharafi_dental` بكل الجداول (مرضى، مواعيد، فواتير+بنود، أطباء، خدمات، مصروفات، عودات، مستخدمون، عملات، وحالة التطبيق).

## 2) تشغيل الخادم
```bash
cd server
npm install
cp .env.example .env      # ثم عدّل بيانات الاتصال
npm start                 # يعمل على http://localhost:4000
```

## 3) ربط الواجهة بالخادم
الواجهة تكتشف الخادم تلقائياً على `http://localhost:4000`. لتغيير العنوان:
- متغير البناء `VITE_API_URL`، أو
- مفتاح المتصفح `localStorage.setItem("dental-api-url", "http://خادمك:4000")` ثم إعادة تحميل.

عندها يتحول مؤشر الشريط العلوي إلى **«MySQL متصل»** وتُزامَن كل تغييراتك فوراً (مع نبضة «مزامنة…» أثناء الحفظ).

## 4) السلوك
- عند التشغيل تجلب الواجهة الحالة المركزية من MySQL وتعمل عليها.
- كل تعديل يُدفَع إلى الخادم (مع تأخير بسيط لتجميع التغييرات) ويُحدَّث داخل معاملة واحدة.
- إذا توقف الخادم، تعود الواجهة تلقائياً للتخزين المحلي دون فقد أي بيانات، وتعود للمزامنة عند توفره.

## 5) واجهات REST (لأدوات التقارير الخارجية)
| المسار | الوصف |
|---|---|
| `GET /api/health` | فحص الاتصال |
| `GET /api/state` / `PUT /api/state` | الحالة الكاملة |
| `GET /api/patients` / `/appointments` / `/invoices` / `/doctors` | قراءة علائقية مباشرة |
